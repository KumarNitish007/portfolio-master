# Nitish Kumar – Portfolio

Personal portfolio website of **Nitish Kumar**, a .NET Full Stack Developer based in Pune, India, building enterprise ERP and healthcare applications with C#, .NET 8, Web API, SQL Server and Angular 19.

**Live site:** https://kumarnitish007.github.io/portfolio-master/

## What's on the site

A single-page, responsive portfolio with these sections:

- **Hero** – who I am and what I build
- **About** – background and approach
- **Skills** – backend, frontend, database and tooling
- **Projects** – selected work, including the open-source [Milkora Dairy Farm Tracker](https://github.com/KumarNitish007/Milkora-Dairy-Farm-Tracker)
- **Experience** – roles and responsibilities
- **Services** – what I can help with
- **Contact** – ways to get in touch, plus a **Download CV** button (also in the header and hero)

## Built with

- Plain **HTML, CSS and JavaScript** (no build step)
- Google Fonts: Inter, Sora and JetBrains Mono
- Hosted on **GitHub Pages** (`main` branch)

## Run locally

No tooling is needed. Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/KumarNitish007/portfolio-master.git
```

## Structure

```
index.html      the whole site (markup, styles and scripts)
assets/         images (e.g. Milkora screenshots) and Nitish_Kumar_CV.pdf
```
